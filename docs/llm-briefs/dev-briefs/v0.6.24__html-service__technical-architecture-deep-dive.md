## Executive Summary

The MGraph-AI HTML Service provides **lossless HTML transformation pipelines** enabling bidirectional conversions between HTML strings, structured dictionaries, typed schemas, and hash-based representations. The architecture supports multiple use cases from simple round-trip validation to complex semantic text processing workflows.

**Core Capabilities:**
- 🔄 **Round-trip preservation**: HTML → Dict → HTML with minimal formatting changes
- 🔐 **Hash-based text extraction**: Replace text content with deterministic hashes
- 📊 **Schema validation**: Type-safe HTML document structures
- 🏷️ **Tag object model**: Programmatic HTML generation with Tag classes
- 🌳 **Tree traversal**: Configurable depth limits and filtering

```
┌─────────────────────────────────────────────────────────────────┐
│                    HTML TRANSFORMATION PIPELINES                 │
└─────────────────────────────────────────────────────────────────┘

INPUT: Raw HTML String
    │
    ├──► Pipeline 1: Basic Round-Trip
    │    Html__To__Html_Dict → Html_Dict__To__Html
    │    USE CASE: Validation, normalization, caching
    │
    ├──► Pipeline 2: Hash Replacement (TEXT EXTRACTION)
    │    Html__To__Dict__Hashes → [External Processing] → Hashes__To__Html
    │    USE CASE: Semantic text processing, translation, rating
    │
    ├──► Pipeline 3: Schema-Based (TYPE SAFETY)
    │    Html__To__Html_Document → [Manipulation] → Html_Document__To__Html_Dict
    │    USE CASE: Validation, tree queries, structured manipulation
    │
    └──► Pipeline 4: Tag Objects (PROGRAMMATIC GENERATION)
         Html__To__Html_Tag → [Modification] → Tag.render()
         USE CASE: Dynamic HTML generation, templating

OUTPUT: Transformed HTML String
```

### Key Implementation Details

**1. Parsing Phase (Html__To__Html_Dict)**

```python
class Html__To__Html_Dict(HTMLParser):
    def handle_starttag(self, tag, attrs):
        new_tag = {"tag": tag, "attrs": dict(attrs), "nodes": []}
        
        if self.current is None:
            self.root = new_tag      # First tag becomes root
        else:
            self.current["nodes"].append(new_tag)
        
        if tag not in VOID_ELEMENTS:
            self.stack.append(new_tag)
            self.current = new_tag
    
    def handle_data(self, data):
        if data.strip():
            text_node = {"type": "TEXT", "data": data}
            self.current["nodes"].append(text_node)
```

**2. Reconstruction Phase (Html_Dict__To__Html)**

```python
def convert_element(self, element, indent_level):
    tag = element.get("tag")
    attrs = element.get("attrs", {})
    nodes = element.get("nodes", [])
    
    # Analyze content type
    has_text_nodes = any(n.get("type") == "TEXT" for n in nodes)
    has_element_nodes = any(n.get("type") != "TEXT" for n in nodes)
    
    # Format based on content
    if has_element_nodes and not has_text_nodes:
        # Pure element content → add newlines
        html = f"<{tag}{attrs_str}>\n{children}\n{indent}</{tag}>\n"
    elif has_text_nodes and not has_element_nodes:
        # Pure text content → inline
        html = f"<{tag}{attrs_str}>{children}</{tag}>\n"
    else:
        # Mixed content → no extra whitespace
        html = f"<{tag}{attrs_str}>{children}</{tag}>\n"
```

### Tree Traversal with Depth Control

```python
class Html__Extract_Text_Nodes:
    def traverse(self, node, depth, parent_tag):
        # Depth limit protection
        if depth > self.max_depth:
            return
        
        # Text node handling
        if node.get("type") == "TEXT":
            data = node.get("data", "").strip()
            if data and parent_tag not in ['style', 'script']:
                node['data'] = self.capture_text(data, parent_tag)
        
        # Recursive traversal
        for child in node.get("nodes", []):
            self.traverse(child, depth + 1, node.get('tag'))
```

### Position Tracking System

**The schema tracks position of every node:**

```python
class Schema__Html_Node:
    attrs       : Dict[str, str]
    child_nodes : List['Schema__Html_Node']      # Element children
    text_nodes  : List[Schema__Html_Node__Data]  # Text children
    tag         : str
    position    : int = -1                       # Position in parent's nodes
```

### Tag Rendering System

**Recursive rendering with indent management:**

```python
class Tag__Base:
    def render_element(self):
        indent = " " * self.indent * INDENT_SIZE  # 4 spaces per level
        
        html = f"{indent}<{self.tag_name}"
        if attrs:
            html += f" {attrs_str}"
        html += ">"
        
        # Content rendering based on node types
        if self.inner_html:
            html += self.inner_html
        
        if self.elements:
            html += "\n"
            for element in self.elements:
                element.indent = self.indent + 1  # Increment indent
                html += element.render()
            html += "\n" + indent
        
        html += f"</{self.tag_name}>"
        return html
```

## Integration Patterns

### Pattern 1: Content Translation

```
┌──────────────────────────────────────────────────────────────────────┐
│                    TRANSLATION WORKFLOW                              │
└──────────────────────────────────────────────────────────────────────┘

1. Extract text with structure
   POST /html/to/dict/hashes
   {
     "html": "<article>...</article>",
     "max_depth": 256
   }
   
   Response: html_dict + hash_mapping + metadata

2. Translate each text segment
   FOR EACH (hash, text) in hash_mapping:
       translated = translation_service.translate(text, target_lang="es")
       modified_mapping[hash] = translated

3. Reconstruct with translations
   POST /hashes/to/html
   {
     "html_dict": original_html_dict,
     "hash_mapping": modified_mapping
   }
   
   Response: Translated HTML with preserved structure

BENEFITS:
✓ Preserve HTML structure (tags, attributes, nesting)
✓ Translate only visible text (not code, not markup)
✓ Maintain text positions (ordered translation)
✓ Cache translations by hash
```

### Pattern 2: Content Safety Rating

```
┌──────────────────────────────────────────────────────────────────────┐
│                   CONTENT RATING WORKFLOW                            │
└──────────────────────────────────────────────────────────────────────┘

1. Extract text nodes
   POST /html/to/text/hashes  ← Lightweight endpoint
   {
     "html": "<article>...</article>"
   }
   
   Response: hash_mapping only (faster)

2. Rate each text segment
   FOR EACH (hash, text) in hash_mapping:
       rating = moderation_service.rate(text)
       IF rating < THRESHOLD:
           filtered_mapping[hash] = "[CONTENT FILTERED]"
       ELSE:
           filtered_mapping[hash] = text

3. Apply filter
   POST /hashes/to/html
   {
     "html_dict": original_html_dict,
     "hash_mapping": filtered_mapping
   }
   
   Response: Filtered HTML

OPTIMIZATION:
• Use /html/to/text/hashes (not /html/to/dict/hashes)
• Cache ratings by hash
• Batch rating requests
```

### Pattern 3: Semantic Search Indexing

```
┌──────────────────────────────────────────────────────────────────────┐
│                  SEMANTIC INDEXING WORKFLOW                          │
└──────────────────────────────────────────────────────────────────────┘

1. Parse HTML structure
   POST /html/to/dict
   {
     "html": "<article>...</article>"
   }
   
   Response: html_dict + metadata

2. Extract text with context
   POST /dict/to/text/nodes
   {
     "html_dict": html_dict,
     "max_depth": 256
   }
   
   Response: text_nodes with {hash, text, tag}

3. Index with context
   FOR EACH (hash, node_data) in text_nodes:
       embedding = embed_model(node_data['text'])
       vector_db.insert({
           'hash': hash,
           'text': node_data['text'],
           'tag': node_data['tag'],          ← Context!
           'embedding': embedding,
           'doc_id': document_id
       })

4. Search and reconstruct
   query_embedding = embed_model(query)
   results = vector_db.search(query_embedding)
   
   FOR EACH result:
       # Highlight relevant text in original HTML
       html_dict = load_cached_html_dict(result.doc_id)
       hash_mapping = {
           result.hash: f"<mark>{result.text}</mark>"
       }
       highlighted = reconstruct_html(html_dict, hash_mapping)

BENEFITS:
✓ Tag context improves search relevance
✓ Exact position tracking enables highlighting
✓ Hash-based deduplication
```

### Appendix A: Complete Class Diagram

```
┌──────────────────────────────────────────────────────────────────────┐
│                     COMPLETE CLASS HIERARCHY                         │
└──────────────────────────────────────────────────────────────────────┘

PARSING:
Html__To__Html_Dict (HTMLParser)
  └─ Methods: handle_starttag, handle_endtag, handle_data
      └─ convert() → dict

Html_Dict__To__Html_Document
  └─ parse_node(dict) → Schema__Html_Document

Html__To__Html_Tag
  └─ Html_Dict__To__Html_Tags
      └─ convert_to__tag() → Tag__Base

RECONSTRUCTION:
Html_Dict__To__Html
  └─ convert_element(dict) → str
  └─ convert_attrs(dict) → str

Html_Document__To__Html_Dict
  └─ node_to_dict(Schema__Html_Node) → dict

TAG HIERARCHY:
Tag__Base
  ├─ Tag__Html
  │   ├─ head: Tag__Head
  │   │   ├─ links: List[Tag__Link]
  │   │   ├─ meta: List[Tag__Base]
  │   │   └─ style: Tag__Style
  │   └─ body: Tag__Body
  ├─ Tag__Div
  ├─ Tag__H
  ├─ Tag__HR
  └─ Tag__Text (special)

HASH EXTRACTION:
Html__Extract_Text_Nodes
  └─ traverse(node, depth)
  └─ capture_text(text, tag) → hash

Html__Hash__Transformations
  └─ html__to__dict__hashes() → Response
  └─ html__to__text__hashes() → Response
  └─ html_dict__with__xxx() → dict

SCHEMA CLASSES:
Schema__Html_Document
  └─ root_node: Schema__Html_Node
  └─ timestamp: Timestamp_Now

Schema__Html_Node
  ├─ tag: str
  ├─ attrs: Dict[str, str]
  ├─ child_nodes: List[Schema__Html_Node]
  ├─ text_nodes: List[Schema__Html_Node__Data]
  └─ position: int

Schema__Html_Node__Data
  ├─ data: str
  ├─ type: Schema__Html_Node__Data__Type
  └─ position: int

QUERY UTILITIES:
Html__Query
  ├─ document: Schema__Html_Document
  ├─ Properties: head, body, title, links, etc.
  └─ Methods: find_by_id, find_by_class, find_by_tag

FASTAPI ROUTES:
Routes__Html
  └─ to__dict(), to__html(), to__dict__hashes(), etc.

Routes__Dict
  └─ to__html(), to__text__nodes(), to__tree__view()

Routes__Hashes
  └─ to__html()
```

## Quick Reference

### Common Operations Cheat Sheet

```python
# 1. Parse HTML
from osbot_utils.helpers.html.transformers.Html__To__Html_Dict import Html__To__Html_Dict
html_dict = Html__To__Html_Dict(html="<p>Text</p>").convert()

# 2. Reconstruct HTML
from osbot_utils.helpers.html.transformers.Html_Dict__To__Html import Html_Dict__To__Html
html = Html_Dict__To__Html(root=html_dict).convert()

# 3. Extract text with hashes
response = client.post('/html/to/dict/hashes', json={'html': html})
hash_mapping = response.json()['hash_mapping']

# 4. Apply modifications
modified_mapping = {hash: modified_text for hash, text in hash_mapping.items()}
response = client.post('/hashes/to/html', json={
    'html_dict': html_dict,
    'hash_mapping': modified_mapping
})

# 5. Query HTML
with Html__Query(html=html) as query:
    title = query.title
    element = query.find_by_id("main")
    all_paragraphs = query.find_by_tag("p")
```
